# 엑셀 주소 → 네이버 지도 자동 저장 (`scripts/naver_map_saver.py`) 사용 안내

엑셀에 **상호명**과 **주소**가 있을 때, 주소를 네이버 지도에서 찾아 원하는 저장 리스트에 넣고
메모에 `상호명 | 상세주소(몇 층 몇 호)` 를 자동으로 적어 주는 스크립트.

## 1. 무엇을 하는가 (예시)

| 엑셀 주소 | 네이버 지도 검색어 | 메모 |
|---|---|---|
| 서울특별시 강남구 역삼동 123-4번지 2층 201호 | 서울특별시 강남구 역삼동 123-4 | 맛있는국밥 \| 2층 201호 |
| 서울특별시 마포구 서교동 395-12번지, 1층 | 서울특별시 마포구 서교동 395-12 | 카페A \| 1층 |
| 서울특별시 용산구 한강대로23길 55 (`번지` 없음) | 주소 전체 | 도로명집 |

- `번지` 앞부분만 검색, `번지` 뒷부분(번지 단어 제외)은 메모로.
- 저장 리스트는 **첫 행에서 한 번만** 번호로 묻고, 이후는 같은 리스트에 계속 저장.
- 주소 칸이 빈 행은 건너뜀.

## 2. 처음 한 번 설치 (Windows 기준)

1. [python.org](https://www.python.org/downloads/) 에서 Python 설치 (설치 화면에서 **Add python.exe to PATH** 체크)
2. 명령 프롬프트(cmd)에서:

```bash
pip install playwright openpyxl
```

```bash
python -m playwright install chromium
```

## 3. 실행

### 방법 A — 더블클릭 (추천)

1. `naver_map_saver.py` 와 `naver_map_saver.bat` 을 같은 폴더에 둔다.
2. **엑셀 파일을 `naver_map_saver.bat` 아이콘 위로 끌어다 놓는다.**
3. 처음 한 번은 필요한 프로그램을 자동 설치 (몇 분 소요).
4. 검색어/메모 미리보기가 나오면 확인 후 `y` 입력.
5. 크롬 창이 뜨면 **처음 한 번 네이버 로그인** → 검은 창에서 Enter → 첫 행에서 리스트 번호 입력 → 이후 자동.

### 방법 B — 명령어

```bash
python naver_map_saver.py 업체목록.xlsx --dry-run
```
→ 브라우저 없이 "검색어 / 메모" 가 제대로 나뉘는지만 미리 확인.

```bash
python naver_map_saver.py 업체목록.xlsx
```

로그인 정보는 같은 폴더의 `naver_map_profile/` 에 저장돼 다음부터는 로그인 생략. **이 폴더는 남에게 주지 말 것** (로그인 세션 포함 가능).

### 자주 쓰는 옵션

| 옵션 | 뜻 |
|---|---|
| `--addr-col 소재지 --name-col 업체명` | 열 이름이 `주소`/`상호명` 이 아닐 때 지정 |
| `--list "배민 매장"` | 리스트를 묻지 않고 바로 지정 |
| `--start 120` | 120번째 행부터 시작 |
| `--auto-only` | 막히면 멈추지 않고 실패로 기록 후 다음 행 |

## 4. 중간에 끊겨도 이어서

- 성공한 행은 `naver_map_saver_done.csv` 에 기록 → **같은 명령을 다시 실행하면 이미 저장한 행은 건너뜀** (중복 저장 안 됨).
- 실패한 행은 `naver_map_saver_failed.csv` 에 이유와 함께 기록.
