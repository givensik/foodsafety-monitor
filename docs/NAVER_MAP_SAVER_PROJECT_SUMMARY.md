# 네이버 지도 자동 저장 도구 — 프로젝트 정리 (2026-11-04 ~ 11-22)

## 1. 한 줄 요약
엑셀의 **상호명·주소**를 읽어 네이버 지도에서 검색하고, ☆ 저장 리스트에 넣으면서 메모에 `상호명 | 상세주소(몇 층 몇 호)`를 자동으로 적어 주는 도구.
요청자는 승환(엑셀 수백 줄을 손으로 하다가 중간에 자꾸 끊겨서 자동화를 원함).

## 3. 동작 순서
엑셀 한 줄마다 반복 (예: `테스트국밥 | 경기 고양시 일산서구 일산동 655-15번지 2층 201호`)

1. 주소를 `번지` 기준으로 자름 → 검색어 `경기 고양시 일산서구 일산동 655-15`, 메모 `테스트국밥 | 2층 201호` (`번지` 단어는 제외, `번지`가 없으면 주소 전체로 검색)
2. 네이버 지도에서 검색
3. 주소 제목 아래 **☆** 클릭 (왼쪽 세로 메뉴의 '저장'은 누르지 않음)
4. **`+메모, 별명, URL`** 펼치기 → 메모 입력
5. **저장 리스트** 클릭 (첫 행에서만 어느 리스트인지 번호로 물어보고 이후 동일 리스트)
6. 맨 아래 **[저장]** 클릭

부가 기능
- 성공한 행은 `naver_map_saver_done.csv`에 기록 → 재실행하면 건너뜀(중복 저장 방지)
- 실패한 행은 `naver_map_saver_failed.csv`에 기록
- 막히면 `naver_map_debug/`에 화면 캡처와 frame별 버튼·입력칸 목록 저장, 수동 처리 대기
- `--dry-run`(브라우저 없이 검색어/메모 미리보기), `--list`, `--start`, `--auto-only`, `--addr-col`, `--name-col`

## 4. 사용한 모듈
- **playwright**: 크롬 조종. `launch_persistent_context`로 로그인 유지, 모든 frame 순회, 화면 좌표로 버튼 선택
- **openpyxl**: 엑셀(.xlsx) 읽기
- Python 기본 모듈: `csv`, `re`, `urllib.parse`, `argparse`, `time`, `pathlib`, `sys`

## 6. 조사 결과: 공식 API / CLI
[확인된 팩트 — 웹 검색, 공식 문서 원문까지 열어 보지는 못함]
- 네이버 지도 **저장 리스트에 장소를 넣는 공개 API는 찾지 못함.**
- 공식 API는 읽기용: 지역 검색(NAVER API HUB `GET /search/v1/local`, 하루 25,000회), Maps Geocoding(주소 → 좌표). 인증은 NCP 키 2개(`X-NCP-APIGW-API-KEY-ID`, `X-NCP-APIGW-API-KEY`).
- `ncloud CLI`는 클라우드 인프라 관리용이라 지도와 무관. 지도용 공식 CLI는 못 찾음.
- 저장 리스트 한도: 5,000곳(보도자료 기준). 엑셀이 5,000줄을 넘으면 리스트를 나눠야 함.
- 자동화는 이용약관에 걸릴 수 있다는 지적이 있음 → 천천히, 소량씩 돌리는 것이 안전.
- 대안: 구글 지도 "내 지도"는 엑셀/시트 일괄 가져오기를 공식 지원.
