# 실시간 신규 공란 모니터링 운영 기록 및 자동 감시 대기 현황

> [!IMPORTANT]
> 본 문서는 **식품의약품안전처(식품안전나라)**의 실시간 채번 전산망에서 새롭게 올라오는 **상호명·소재지 공란(가등록) 레코드**를 감시·추적하고, **클라우드플레어 서버리스 자동화([store.givensik.space](https://store.givensik.space))**를 통해 지자체(새올) 원천망과 즉시 교차 매칭하는 상시 운영 기록입니다.

## 1. 클라우드플레어 자동 감시 대기 현황 (Active Standing Status)

* **서비스 프로덕션 엔드포인트**: [https://store.givensik.space](https://store.givensik.space)
* **운영 인프라**: Cloudflare Pages + Pages Functions (`functions/api/businesses.js`, `functions/api/ledger.js`)
* **상태 저장소**: Cloudflare KV Namespace (`DETECTED_STORES`, `id: 6c55919c3d3c423d9d9f98013cdfe631`)
* **연동 원천 데이터망**:
  1. **식약처 식품안전나라**: 실시간 신규 웹 등록 목록 (`searchBsnList.do`) 및 16자리 상세 원장 (`bsnInfoDetail.do`)
  2. **서울시 열린데이터광장(새올 행정시스템)**: 서울 25개 자치구 인허가 OpenAPI (`LOCALDATA_*`) 전역

### 🛡️ 현재 가동 중인 대기 모드 동작 원리
1. 사용자가 대시보드에 접속하거나 실시간 조회가 일어날 때마다 최신 채번 대장번호를 검사합니다.
2. **신규 공란 발생 감지 조건**:
   - `BSSH_NM: ""` (상호명 공란)
   - `is_pending_name: true` (가등록 상태)
3. **즉시 자동 교차 매칭 파이프라인 작동**:
   - 관할 지자체 코드(예: `종로 JN`, `강북 GB`, `강남 GN`, `강서 GS` 등 25개 자치구) 자동 라우팅
   - 당일 인허가일자(`permitDate`) 및 상세 팝업 위생업태(`subType`), 대표자 마스킹값(`PRSDNT_NM`) 4중 교차 필터링
   - 매칭 즉시 UI에 **`[새올 자동 매칭: {상호명} (신뢰도 {N}%)]`** 에메랄드 뱃지 노출 및 원천 도로명 주소 자동 복원
   - Cloudflare KV에 7일간 캐싱하여 이후 조회 시 0ms 즉시 응답

## 3. 신규 공란 발생 메커니즘 및 집중 감시 시간대 (골든 타임)

식약처와 지자체 새올망의 전산 배치 주기 실측에 근거한 타임라인입니다:

```
[주간 근무시간 (09:00~17:30)]
  • 각 구청 담당자가 새올 시스템에 인허가 등록/결재 진행
  • 오전 09:00~10:00 식약처 아침 배치가 작동하여 전일/야간 등록분의 상호명을 모두 채워둠 (공란 0건)
        ▼
[퇴근 직전/직후 골든타임 (17:30 ~ 20:00 KST) ★집중 모니터링★]
  • 구청 마감 결재건이 식약처 중앙 DB로 대량 전송됨
  • 16자리 대장번호(BSN_LCNS_LEDG_NO)가 대량 생성되면서 상호·주소가 비어있는 "공란(가등록)" 상태 선행 노출
        ▼
[클라우드플레어 실시간 자동 매칭 가동]
  • 신규 채번(`...418511` 이후) 감지 시 서울시 새올 OpenAPI를 백그라운드 호출하여 상호 복원
        ▼
[야간/익일 아침 동기화 (20:00 ~ 익일 10:00)]
  • 식약처 내부 배치가 뒤늦게 돌면서 웹 원장에도 상호명이 채워짐 (평균 14~72시간 소요)
```

## 5. 실시간 추적 실행 가이드

터미널 또는 웹 환경에서 즉시 새로운 공란과 경계 번호를 추적하는 방법입니다:

### 1) 웹 대시보드 실시간 확인
* 주소: [https://store.givensik.space](https://store.givensik.space)
* 기능: 상단 검증기에 `2026001000418510` 입력 후 `+1 다음 번호 생성 확인` 버튼을 누르면 실시간 생성 여부 즉시 판정

### 2) CLI 터미널 1회성 즉시 점검 스크립트
```bash
python3 scripts/monitor_weekday_evening.py
```
* 대시보드 API 최신 상태 및 전국 물리적 경계 번호(`418510` 전후) 자동 스캔 및 신규 공란 발생 시 즉시 콘솔 출력.
